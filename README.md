A GitHub-compatible git forge in one Node 22 process with no dependencies: git smart HTTP (protocol v0 and v2), the REST v3 API, GraphQL and an MCP server, all backed by one in-memory store. It has no git binary and no npm packages.

## Run it

```sh
MAKEFUN_SHOP_TOKEN=<token> node main.ts
```
